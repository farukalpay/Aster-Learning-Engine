# Pipe Lab

`rusted_pipe.astergraph` is the first production-runtime asset proof for Aster.
It describes a rusted hollow pipe as an Aster-owned asset contract: pipe body,
bevel modifier, weld seams, rust and wetness masks, UV islands, LOD chain,
collision proxy, prefab variant, and cook report.

The graph cooks to `assetgraphbin` and the same runtime asset is used by the
`industrial-pipe` preview scene and a small Lumen Run placement.
